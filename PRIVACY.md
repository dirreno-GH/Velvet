# Privacy Policy

Velvet Vault is designed to work locally on the user's computer.

The application does not transfer personal information, passwords, notes,
schedules, tasks, finance entries, documents, or timer text to any networked
system unless a user explicitly chooses an operating-system action that does so.

Vault data is stored locally. Password-vault contents are encrypted before
being written to disk. Other hub data is stored locally in the VelvetVault
application-data directory.

The timer speech feature uses the Windows speech synthesizer installed on the
local computer.

Velvet does not include telemetry, analytics, advertising, or background
network communication in the current 2.1 release.
